# Vrinda Store Sales Dashboard

An Excel-based sales dashboard created to analyze Vrinda Store's 2022 sales and order data.

## About the Project

This project focuses on exploring sales performance and customer order patterns using Microsoft Excel. The dashboard brings different aspects of the sales data together in one place to make the information easier to understand.

## Dashboard Highlights

The dashboard includes:

* Monthly sales and order trends
* Sales comparison by gender
* Order status analysis
* Top 10 states by sales
* Age group and gender-wise order analysis
* Sales contribution by sales channel
* Interactive filters for month, category, and sales channel

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning & Analysis

## Key Analysis

Some of the areas explored in this dashboard include:

* How sales and orders changed throughout the year
* Which states contributed more to overall sales
* Comparison of sales between men and women
* Order status distribution
* Customer order patterns across different age groups
* Contribution of different sales channels
